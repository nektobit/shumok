# Shumok
Сайт живет тут: [https://nektobit.github.io/shumok/](https://nektobit.github.io/shumok/)

## О проекте
Shumok — веб‑приложение для прослушивания и смешивания фоновых звуков (дождь, ветер, волны и т.д.).
В приложении есть общий play/pause для всех звуков, отдельные плееры для каждого трека и редактор
палитры: добавление/удаление звуков, изменение названия/URL/категории, а также импорт/экспорт списка
в JSON и сохранение в localStorage.

## Зачем нужен этот проект
Сайт помогает работать продуктивнее: белый шум и природные звуки создают фон, который меньше отвлекает,
и помогает сосредоточиться на задачах.
